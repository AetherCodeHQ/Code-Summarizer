# Code-Summarizer

Summarize large codebases

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/Code-Summarizer.git
cd Code-Summarizer
go build -o code-summarizer .
```

## Usage

```bash
.code-summarizer .
.code-summarizer --path ./src
```
